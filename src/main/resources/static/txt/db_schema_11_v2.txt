LOMBOK ANNOTATIONS (Code Generation)
┌─────────────────────┬──────────────────────────────────────────────────────────┐
│ Annotation          │ Purpose & What it Generates                              │
├─────────────────────┼──────────────────────────────────────────────────────────┤
│ @Data               │ Generates: getters, setters, toString, equals, hashCode │
│ @NoArgsConstructor  │ Generates: constructor with no parameters               │
│ @AllArgsConstructor │ Generates: constructor with all fields                  │
│ @Builder            │ Generates: builder pattern for object creation          │
│ @Getter / @Setter   │ Generates: only getters or setters                      │
│ @ToString           │ Generates: toString method                               │
└─────────────────────┴──────────────────────────────────────────────────────────┘

JPA ANNOTATIONS (Database Mapping)
┌─────────────────────┬──────────────────────────────────────────────────────────┐
│ Annotation          │ Purpose & Example                                        │
├─────────────────────┼──────────────────────────────────────────────────────────┤
│ @Entity             │ Marks class as database table                            │
│ @Table              │ Specifies table name: @Table(name = "restaurants")       │
│ @Id                 │ Marks field as primary key                               │
│ @GeneratedValue     │ Auto-increment ID: (strategy = GenerationType.IDENTITY)  │
│ @Column             │ Maps to DB column: @Column(name = "price_range")         │
│ @JoinColumn         │ Defines foreign key: @JoinColumn(name = "user_id")       │
│ @ManyToOne          │ Many records → one record relationship                   │
│ @OneToOne           │ One record → one record relationship                     │
│ @OneToMany          │ One record → many records relationship                   │
│ @ManyToMany         │ Many records → many records relationship                 │
└─────────────────────┴──────────────────────────────────────────────────────────┘

JAKARTA VALIDATION ANNOTATIONS (Data Validation)
┌─────────────────────┬──────────────────────────────────────────────────────────┐
│ Annotation          │ Purpose & Example                                        │
├─────────────────────┼──────────────────────────────────────────────────────────┤
│ @NotNull            │ Field cannot be null                                     │
│ @NotBlank           │ String cannot be null, empty, or whitespace              │
│ @Email              │ Validates email format                                   │
│ @Min / @Max         │ Validates numeric range: @Min(1) @Max(3)                 │
│ @Size               │ Validates length: @Size(min = 1, max = 100)              │
│ @Pattern            │ Validates regex: @Pattern(regexp = "\\d{3}-\\d{4}")      │
└─────────────────────┴──────────────────────────────────────────────────────────┘
